# Webwave
재미있는 사이트들을 모아보고 추천해주는 사이트

## 로컬 개발

- Node.js 설치 후 `npm install`, `npm run dev` 실행.
- `npm run build`: 프런트엔드 빌드 확인.
- `node --test server/github.test.js`: 서버 캐시와 장애 처리 검증.
- `npm run preview`: 빌드한 화면과 GitHub API 함께 확인.

### GitHub 연결

`src/websites.js`의 작품에 `github: 'owner/repository'`를 지정합니다.
현재 SMASH 저장소를 예시로 연결했으며 제작자 본인 인증을 의미하지 않습니다.
브라우저는 `/api/github`를 요청하고 서버가 GitHub 공개 API를 호출합니다.
정상 결과는 서버 메모리에서 10분간 공유하며 동시 요청을 병합합니다.
실패하면 기존 수치를 오래된 데이터로 표시하고 1분 뒤 재시도할 수 있습니다.
필요할 때 `.env.local`에 `GITHUB_TOKEN`을 설정할 수 있습니다. 토큰은 선택 사항이며 서버에서만 읽습니다.
`VITE_` 접두사로 토큰을 만들거나 Git에 올리지 마세요.

### 현재 구현 범위

- GitHub 누적 스타 순위, 최신 정식 릴리스, 최근 코드 푸시 시각.
- 10분/30분 자동 갱신과 수동 갱신. 백그라운드에서는 자동 요청을 멈추고 복귀 시 갱신합니다.
- Vite 개발/미리보기 서버에서 API를 제공합니다. `dist`만 정적 호스팅하면 API는 작동하지 않습니다.
- 공개 운영 전에는 별도 운영 서버/서버리스 API와 영속 캐시로 이전해야 합니다.
- 제작자 등록·소유권 인증·공용 데이터베이스는 아직 없습니다.
- Webwave 방문 수는 브라우저별 체험 기록이며 전체 방문 수가 아닙니다.
